One image that sums up the world's news of Wednesday, 25 November 2026:
a newspaper front page with a lead story, 34 short stories across
7 world regions, and a world-map strip marking where the stories
happened.

Lead story: Ukraine sinks a Russian ship as the war spreads beyond
Europe — Kyiv confirms drone strikes on a Russian cargo ship in the
Gulf of Finland and a warship off Libya, as NATO sends an AWACS
plane to Poland.

## Run it

```sh
python3 render.py   # redraws entry.png (1024x1024, PIL + DejaVu fonts)
python3 main.py     # copies entry.png to $MAKEFUN_OUTPUT_DIR/entry.png
```

`main.py` uses only the standard library. It validates that the
output is a real PNG under the 1 MiB size gate.
